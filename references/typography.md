# 字体、字阶与跨语言排版

## 选择顺序

先检查现有字体与品牌规定，再按字形覆盖、实际字号可读性、可用字重、网页嵌入许可、文件体积和视觉性格选择。默认一至两种设计字体；代码可单独使用等宽字体，语言 fallback 不计入这一数量建议。

系统字体、Inter 或 Roboto 可以是成熟界面的正确选择；判断的是设计意图与实际表现，不是字体是否“常见”。不为差异化牺牲识字、数字区分或加载速度。

| 角色 | 应检查 | 可考虑的方向（并非默认字体套餐） |
|---|---|---|
| 品牌标题 | 多行形状、重音与标点、品牌语气 | 有性格的无衬线或展示衬线 |
| 长篇正文 | 小字号字腔、连续段落舒适度 | 人文无衬线或正文衬线 |
| 密集 UI | 中小字号、状态文本、字重差异 | 单一家族及系统 UI 字体 |
| 数字/规格 | 0/O、1/l/I、单位和小数点 | 等宽数字 `tabular-nums`，不必全用等宽字体 |
| 中文 | 简繁字形、拉丁文协调、标点 | 匹配品牌的中文家族及地区 fallback |

命名字体之前确认其可获取和许可；CSS 写了家族名不代表浏览器已加载它。

## 字阶、行高、行长

字号比值 1.2 或 1.25 可用于初始层级，之后按实际内容调整；并非 WCAG 要求。小屏标题通常需要更温和的级差。明确区分“严格比例字阶”和“经过光学校正的角色字号”。

可用起点：正文 1–1.125rem、行高 1.5–1.75；拉丁文展示标题行高 1.1–1.25；中文/多语言标题从 1.25–1.4 开始检查。辅助文字通常 0.875rem 起，重要信息不因视觉权重低而难以阅读。以上均是启发式，需要用目标字体验证。

拉丁文正文可从 60–70ch 起，45–75 个字符/行是常用经验区间。`ch` 是字体中 0 的宽度，**不是精确字符数**。中文正文可从 30–40em 起，根据语言与视口测试；不把 65ch 等同于 65 个汉字。移动端自然会有更短行。

标题优先通过宽度、字号和文案形成好的换行；必要时渐进使用 `text-wrap: balance`。不要在所有屏幕上硬编码 `<br>`，不要为了视觉统一截断用户必须阅读的内容。

## 流式字号需要真实端点

对于视口端点 W₀、W₁（CSS px）与字号 S₀、S₁（设计 px）：

```text
m = (S₁ - S₀) / (W₁ - W₀)
b = S₀ - m × W₀
clamp(S₀/R rem, calc(b/R rem + 100m vw), S₁/R rem)
```

R 是计算时的根字号假设，默认 16px；不要为了匹配公式强制设置用户根字号。公式仅在该假设下精确经过端点。随根字号变化，流式区间与实际尺寸也会变化，仍须测试用户字体设置、200% 缩放及文本放大。

例如 `python3 scripts/design_math.py fluid 16 20 360 1280` 输出 360–1280px 之间从 16 到 20px 的 CSS。不应只看 `clamp` 中的 min/max 就声称某个特定设备恰好达到这两个值。

## 多语言与韧性

- 文档设置正确 `lang` 和 UTF-8；嵌套语言变化、阿拉伯文/希伯来文方向按内容标注。布局优先逻辑属性，必要时用 `dir`/`bdi` 隔离混合方向文本。
- 中文字体栈可包含 `PingFang SC`、`Noto Sans CJK SC`、`Microsoft YaHei` 与通用 fallback；繁体与日文选择匹配语言的字体，不能一律用简体替代。
- 中文避免对整段应用 `word-break: break-all`；普通文字正常断行，长 URL/无空格标识符用 `overflow-wrap: anywhere` 局部处理。
- 不把中文强制大写或沿用拉丁字母的大幅字距；中文多行标题检查上下字形是否相碰。
- 德语长词、阿拉伯文方向、货币单位和长按钮文案应纳入实际目标语言的压力测试，别机械按字符数截断。
- 只在短且确实不可拆分的单位/代号上使用不换行；窄屏标签必须允许适当换行。

## 字体加载

已安装本地字体或系统字体不需要重复引入。嵌入字体通常使用 WOFF2 和恰当的 `font-display`；按实际首屏需求决定预加载，避免预加载所有字重。CJK 全量字体可能很大，先考虑系统 fallback 或可靠的按字形分片，不随意删掉用户内容可能需要的字符。

观察字体成功、失败、慢加载三种情况。仅在量测过目标字体后设置 `size-adjust` 等指标覆盖，不能猜值来宣称消除布局跳动。

## 常见误用与替代

| 误用 | 替代 |
|---|---|
| 只用灰度深浅建立层级 | 同时通过字号、字重、位置和间距传达关系，并测对比度 |
| 色相相近就认定易读 | 计算实际前景/背景的相对亮度对比 |
| 全局隐藏溢出 | 定位产生溢出的元素并修正尺寸与换行 |
| 固定卡片高度保齐 | 自然高度、合理对齐与明确的媒体比例 |
| 所有标签 `nowrap !important` | 只保护确需整体呈现的短语，其余允许重排 |
| 为满足比例挤压正文 | 以阅读体验修正 token，不让数学比例主导内容 |
